## ロックと非表示の違い

「非表示」は、写真をライブラリや通常のアルバムから外して目に入らなくする操作です。「ロック」は、写真がある場所を開くときに認証を求める仕組みです。iOS 16以降の「非表示」アルバムはこの両方を兼ねていて、写真をライブラリから外したうえで、アルバムを開くときにFace IDなどを求めます。さらに強い方法として、写真を独自の鍵で暗号化して保管するアプリもあります。

| | 非表示 | ロック（認証で開く） | 暗号化して保管 |
|---|---|---|---|
| 何をするか | 写真をライブラリから外す | 開く前にFace IDなどを求める | 写真を独自の鍵で暗号化して別の場所に保存 |
| iOSでの例 | 「非表示」アルバム | 「非表示」アルバムのロック、アプリのロック | ロックしたメモ（カスタムパスワード） |
| 開くのに必要なもの | なし（ロックをオフにした場合） | Face ID / Touch ID / パスコード | メモのパスワードやアプリ独自の鍵 |
| パスコードを知る人 | 見られる | 見られる | 別の鍵を知らなければ見られない |
| 送信済みのコピー | 守られない | 守られない | 守られない |

iPhoneの中のデータは「データ保護」という仕組みで端末ごと暗号化されています。ただ、iPhoneのロックが解除されている間は、写真アプリのロックは「開く前の確認」として働くもので、写真を別の鍵で包み直すわけではありません。**誰から守りたいのかによって、「ロック」で足りるのか「別の鍵」が必要なのかが決まります。** 写真を隠す方法全体の比較は[iPhoneで写真を非表示にする方法](/ja/guides/iphone-hide-photos/)にまとめています。

## 「非表示」アルバムを使って写真をロックする方法（iOS 26・iOS 27）

いちばん手軽で、追加のアプリもいらない方法です。iOS 16以降は「非表示」と「最近削除した項目」が標準でロックされているので、写真を移してから設定を確かめるだけで済みます。

### ステップ1：ロックしたい写真を選ぶ

写真アプリを開き、右上の「選択」をタップして、ロックしたい写真やビデオを順にタップします。1枚だけなら、その写真を開いた状態でもかまいません。

### ステップ2：「非表示」をタップする

「その他」ボタン（…）をタップし、「非表示」を選びます。確認が表示されたら、もう一度「非表示」をタップします。選んだ写真はライブラリから消え、「非表示」アルバムに移ります。

### ステップ3：「Face IDを使用」がオンか確認する

「設定」＞「アプリ」＞「写真」を開き、「Face IDを使用」がオンになっていることを確かめます。Touch ID搭載機では「Touch IDを使用」、生体認証を使っていない場合は「パスコードを使用」と表示されます。

### ステップ4：ロックがかかっているか確かめる

写真アプリで「コレクション」＞「ユーティリティ」＞「非表示」を開き、「アルバムを表示」をタップしたときに認証が求められれば完了です。

iOS 18では、ステップ4のアルバムは写真アプリの画面を上にスワイプした先の「ユーティリティ」にあります。iOS 16・17では、ステップ3の設定が「設定」＞「写真」にあり、アルバムは「アルバム」タブの「その他」の下です。ロックの設定は「非表示」と「最近削除した項目」の両方にかかり、オフにするとどちらも認証なしで開けるようになります。アルバムの場所が見つからない場合は[非表示アルバムはどこにある？](/ja/guides/hidden-album-location/)を参照してください。

## 「非表示」アルバムのロックが本当のロックではない理由

「非表示」アルバムのロックは、写真アプリの中で「このアルバムを開いてよいか」を確認する仕組みです。写真そのものに別のパスワードがかかるわけではないため、次のような経路は防げません。

| 経路 | 守られるか | 理由 |
|---|---|---|
| ライブラリをスクロールする人 | 守られる | 写真がライブラリに表示されない |
| iPhoneのパスコードを知っている人 | 守られない | 認証画面でパスコードを入力すれば開ける |
| 「設定」を開ける人 | 守られない | 「Face IDを使用」をオフにすればロック自体が外れる |
| Face IDに「もう一つの容姿」を登録された人 | 守られない | その人の顔でも認証が通る |
| 同じApple Accountで同期している別の端末 | 守られない | iCloud写真で非表示の写真も同期される |
| 送信済み・保存済みのコピー | 守られない | iPhoneの写真とは別のデータになっている |

つまり、このロックが役に立つのは「パスコードを知らない人」に対してです。パスコードを知っている相手がどんな手順でロックを越えうるのか、その防ぎ方は[非表示アルバムのFace IDは解除できる？](/ja/guides/hidden-album-face-id-bypass/)で詳しく取り上げています。

## 暗号化された保管庫アプリで写真をロックする方法

iPhoneのパスコードとは無関係の鍵で写真を守りたい場合は、写真を暗号化して保存する保管庫アプリを使う方法があります。動画もまとめて扱えるのが利点ですが、アプリによって作りの差が大きいジャンルです。ここでは特定のアプリではなく、一般的な手順と確認点を説明します。

### ステップ1：信頼できるアプリかを確かめる

App Storeの説明で、写真を暗号化して保存すること、その方式や鍵の扱いが明記されているかを確認します。あわせて、App Storeのプライバシーラベルで収集されるデータが必要最小限かも見ておきます。

### ステップ2：iPhoneとは別のパスコードを設定する

アプリを開いたら、iPhoneのパスコードとは違うパスコードやパスワードを設定します。同じ番号にすると、iPhoneのパスコードを知っている人にそのまま開けられてしまいます。

### ステップ3：写真を取り込む

アプリの取り込み機能で、写真アプリから守りたい写真を選んで保管庫に入れます。アプリに写真ライブラリへのアクセスを求められた場合は、必要な写真だけを選ぶ設定にしておくと安心です。

### ステップ4：写真アプリの元の写真を削除する

取り込んだだけでは、元の写真は写真アプリに残ったままです。写真アプリで元の写真を削除し、「最近削除した項目」からも削除します。

### ステップ5：復旧方法を確認しておく

パスコードを忘れたときの復旧方法と、アプリを削除したり機種変更したりしたときに写真がどうなるかを確認します。復旧手段がないアプリでは、パスコードを忘れると写真を取り出せなくなることがあります。

アプリ選びの基準は[写真保管庫アプリの選び方](/ja/guides/photo-vault-apps-guide/)で詳しく解説しています。

## 写真をロックする方法の比較

| 方法 | 開くのに必要なもの | パスコードを知る人から守れるか | 動画 | 主な注意点 |
|---|---|---|---|---|
| 「非表示」アルバムのロック | Face ID / Touch ID / パスコード | 守れない | 可 | iCloud同期先の端末でも見られる |
| 写真アプリのロック（iOS 18以降） | Face ID / Touch ID / パスコード | 盗難デバイスの保護で外出先は可 | 可 | 端末ごとの設定。写真アプリは隠せない |
| ロックしたメモ（カスタムパスワード） | メモのパスワード（またはFace ID） | 守れる | 不可 | 忘れると復元不可。元写真の削除が必要 |
| 暗号化された保管庫アプリ | アプリ独自のパスコードなど | アプリの作り次第 | アプリ次第 | 信頼性の見極めと元写真の削除が必要 |

ちょっとした覗き見対策なら「非表示」アルバム、写真アプリを開かせたくないならアプリのロック、少数の写真をパスワードで確実に守りたいならロックしたメモが向いています。方法はひとつに絞る必要はなく、普段の写真は写真アプリごとロックし、特に見られたくない数枚だけをカスタムパスワードのメモに移す、といった組み合わせも有効です。

## iPhoneで写真をロックする他の方法

### 写真アプリそのものをロックする（iOS 18以降）

ホーム画面で写真アプリのアイコンを長押しし、「Face IDを必要にする」（機種によって「Touch IDを必要にする」「パスコードを必要にする」）をタップすると、写真アプリ全体を開くのに認証が必要になります。Appleの説明では、ロックしたアプリの情報は通知のプレビュー、検索、Siriからの提案などにも表示されず、アプリを閉じると自動的に再びロックされます。解除するときは、同じメニューで「Face IDを必要にしない」を選びます。

写真アプリは最初から入っているアプリなので、アプリライブラリの「非表示」フォルダには隠せません。また、ロックはその端末だけの設定で、iCloudでは同期されません。

さらに「設定」＞「Face IDとパスコード」で「盗難デバイスの保護」をオンにすると、iPhoneが自宅や職場など普段いる場所から離れているとき、ロックしたアプリはFace IDかTouch IDでしか開けなくなります。「セキュリティ継続が必要」を「常に」にすると、場所に関係なくこの扱いになります。

### ロックしたメモに写真を入れる

メモアプリは、メモごとにロックをかけられます。「設定」＞「アプリ」＞「メモ」＞「パスワード」で「カスタムパスワードを使用」を選ぶと、iPhoneのパスコードとは別のパスワードで守れます。iCloudのメモなら、ロックしたメモはエンドツーエンドで暗号化されます。

メモアプリで新規メモを作り、添付ボタンから写真を追加したら、メモアクションボタンから「ロック」をタップします。写真アプリに残っている元の写真は削除し、「最近削除した項目」からも削除してください。メモアプリのカメラで直接撮影すれば写真アプリを経由しませんが、「設定」＞「アプリ」＞「メモ」の「“写真”に保存」がオンだと写真アプリにも保存されます。

ロックしたメモでもタイトルは一覧に表示されるので、1行目に内容がわかる言葉を書かないようにしましょう。PDFやビデオ、オーディオなどを含むメモはロックできません。

> カスタムパスワードを忘れ、Face IDやTouch IDでも開けなくなると、Appleでもロックしたメモを復元できません。パスワードをリセットしても、それまでにロックしたメモは開けないままです。パスワードは必ず確実に覚えておける方法で管理してください。

### ファイルアプリに移す

写真を「ファイル」アプリの「このiPhone内」などに保存し、写真アプリから削除する方法もよく紹介されます。写真アプリのライブラリには出てこなくなりますが、ファイルアプリにはフォルダごとにパスワードをかける機能がありません。ファイルアプリを長押ししたメニューに「Face IDを必要にする」が表示されればアプリ全体をロックできますが、鍵はiPhoneのパスコードと同じです。保存先をiCloud Driveにすると、同じApple Accountのほかの端末やパソコンからも見られます。

## ヒントとよくある間違い

- **パスコードを人前で入力しない**：「非表示」アルバムもアプリのロックも、パスコードを知られると開けられます。普段はFace IDを使い、知られた心当たりがあれば変更しましょう。
- **Face IDの登録内容を見直す**：「設定」＞「Face IDとパスコード」で「もう一つの容姿」を家族の顔で登録していると、その人もロックを解除できます。心当たりがあれば「Face IDをリセット」して登録し直します。
- **ほかのアプリのアクセス権を確認する**：写真アプリのロックは写真アプリを開く操作にかかるもので、写真へのアクセスを許可したほかのアプリの写真選択画面までロックされるとは、Appleは説明していません。「設定」＞「プライバシーとセキュリティ」＞「写真」で見直してください。
- **元の写真を消し忘れない**：メモや保管庫アプリに移したあと、写真アプリと「最近削除した項目」に元の写真が残っているのはよくある間違いです。
- **外に出たコピーを忘れない**：メッセージで送った画像やクラウドストレージに自動アップロードされた写真は、iPhoneの写真をロックしても守られません。
