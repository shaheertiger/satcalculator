## Face IDのロックと別の鍵による保護の違い

「非表示」アルバムのFace IDロックは、写真アプリが「このアルバムを開いてよいか」を確認する仕組みです。Face IDで認証できないときはiPhoneのパスコードで代わりに開けるように作られていて、Appleのユーザガイドでも、「非表示」と「最近削除した項目」はFace ID・Touch ID・パスコードのいずれかでロックを解除すると説明されています。これに対して、カスタムパスワードでロックしたメモなどは、iPhoneのパスコードとは別の鍵で守られます。

| | 「非表示」アルバムのFace IDロック | 別の鍵による保護（ロックしたメモなど） |
|---|---|---|
| 開くときに確認するもの | Face ID / Touch ID / パスコード | メモのパスワードやアプリ独自の鍵 |
| iPhoneのパスコードで開けるか | 開ける | 開けない（カスタムパスワードの場合） |
| ロックをオフにできる人 | iPhoneのロックを解除できる人 | 別の鍵を知っている人 |
| 同じApple Accountの別の端末 | 同期された写真を見られる | 同じ鍵がなければ開けない |
| パスコードを知らない人 | 開けない | 開けない |

**Face IDのロックが破られるのではなく、正規の代替手段であるパスコードで開けられる**というのが実態です。逆に言えば、パスコードを知らない人は認証画面を通れず、「設定」を開いてロックを外すこともできません。まだ信頼していないパソコンを「信頼」させるにもiPhoneのロック解除が必要です。iPhoneを一時的に貸した相手や、たまたま画面をのぞいた人に対しては、「非表示」アルバムは期待どおりに働きます。

## 写真アプリをFace IDでしか開けないようにする方法（iOS 26・iOS 27）

「非表示」アルバム単体では、パスコードでの解除を止められません。ただしiOS 18以降は、写真アプリそのものをロックし、「盗難デバイスの保護」と組み合わせることで、ロックしたアプリをFace IDかTouch IDでしか開けない状態にできます。

### ステップ1：「盗難デバイスの保護」をオンにする

「設定」＞「Face IDとパスコード」を開いてパスコードを入力し、「盗難デバイスの保護」をタップしてオンにします。利用にはiOS 17.3以降、2ファクタ認証、Face IDまたはTouch ID、「探す」などが必要です。

### ステップ2：「セキュリティ継続が必要」を「常に」にする

同じ画面で「セキュリティ継続が必要」を「常に」にします。初期設定の「普段いる場所から離れているとき」のままだと、自宅や職場ではパスコードも使えます。

### ステップ3：写真アプリをロックする

ホーム画面で写真アプリのアイコンを長押しし、「Face IDを必要にする」をタップします。確認画面でもう一度「Face IDを必要にする」を選びます。

### ステップ4：Face IDで開けることを確かめる

いったんホーム画面に戻り、写真アプリをタップしてFace IDで開けることを確認します。Appleの説明では、「盗難デバイスの保護」が働いている間、ロックしたアプリを開くのにパスコードは使えません。

> 「セキュリティ継続が必要」を「常に」にすると、パスコードの変更やFace IDの追加・削除などに1時間の待機時間と再度の生体認証が必要になります。急いで設定を変えたいときに困らないよう、仕組みを理解してからオンにしてください。

アプリのロックはその端末だけの設定で、iCloudでは同期されません。同じApple AccountのiPadにも写真があるなら、iPad側でも対策が必要です。ほかのロック方法との違いは[iPhoneの写真をロックする方法](/ja/guides/lock-photos-iphone/)で比較しています。

## 「非表示」アルバムのFace IDが本当のロックではない理由

「非表示」アルバムに入られる経路は、パスコードの入力だけではありません。主な経路を整理すると次のとおりです。

| 経路 | 必要なもの | 主な対策 |
|---|---|---|
| 認証画面でパスコードを入力 | iPhoneのパスコード | パスコードを変更し、人前で入力しない |
| 「設定」で「Face IDを使用」をオフ | iPhoneのロック解除（パスコード） | 同上 |
| Face IDに登録された「もう一つの容姿」 | 登録された本人の顔 | Face IDをリセットして登録し直す |
| 同じApple Accountで同期している別の端末 | その端末のパスコード | 端末のサインインや同期を見直す |
| 家族共用のMac | Macのログインパスワード | Macのログインユーザーを分ける |
| 信頼済みのパソコン | 過去に「信頼」したパソコン | 信頼の設定をリセットする |

いちばん多いのは、パートナーや家族が日常的にパスコードを知っているケースです。パスコードがわかれば、認証画面でそのまま入力することも、「設定」＞「アプリ」＞「写真」で「Face IDを使用」をオフにしてロックそのものを外すこともできてしまいます。Macの写真アプリでは「非表示」アルバムをTouch IDかMacのログインパスワードで開くので、共用のMacでは家族も開けます。パソコンについても、Appleは信頼されたコンピュータがiPhoneの写真やビデオにアクセスできると説明しています。

## パスコードを知られたときに抜け道をふさぐ方法

### ステップ1：パスコードを変更する

「設定」＞「Face IDとパスコード」を開いて現在のパスコードを入力し、「パスコードを変更」をタップします。「パスコードオプション」から、推測されにくい「カスタムの英数字コード」も選べます。

### ステップ2：Face IDの登録内容を見直す

「設定」＞「Face IDとパスコード」で「もう一つの容姿」を家族の顔で登録した覚えがあれば、「Face IDをリセット」して自分の顔だけを登録し直します。「設定」＞「アクセシビリティ」＞「Face IDと注視」で「Face IDを使用するには注視が必要」がオンになっているかも確認します。

### ステップ3：サインイン中のデバイスを確認する

「設定」の一番上の自分の名前をタップし、同じApple Accountでサインインしているデバイスの一覧を確認します。使っていない端末や家族の端末は、サインアウトするかiCloud写真の同期をオフにします。

### ステップ4：信頼済みのパソコンをリセットする

過去にどのパソコンを信頼したか覚えていない場合は、「設定」＞「一般」＞「転送またはiPhoneをリセット」＞「リセット」＞「位置情報とプライバシーをリセット」を選びます。データは消えませんが、位置情報やプライバシーの許可も初期状態に戻ります。

## 対策ごとの効果の比較

| 対策 | ふさげる経路 | 手間・注意点 |
|---|---|---|
| パスコードの変更 | パスコード入力、設定でのロック解除 | 新しいパスコードを人前で入力しない |
| Face IDのリセット | 「もう一つの容姿」での解除 | 自分の顔を登録し直す必要がある |
| サインイン中のデバイスの整理 | 同期している別の端末 | 家族の端末から写真が見えなくなる |
| 信頼済みパソコンのリセット | 過去に信頼したパソコン | 位置情報やプライバシーの許可も初期化される |
| 写真アプリのロック＋盗難デバイスの保護「常に」 | パスコードでの写真アプリの起動 | 設定変更に1時間の待機時間がかかる |
| ロックしたメモ・保管庫アプリへの移動 | iPhoneのパスコードによる閲覧全般 | 別の鍵の管理と元写真の削除が必要 |

## Face ID以外で写真を守る他の方法

### スクリーンタイムパスコードを使う

スクリーンタイムには、iPhoneのパスコードとは別の「スクリーンタイムパスコード」を設定できます。写真アプリに使用時間の制限をかけ、延長にこのパスコードを求めれば、壁を1枚増やすことはできます。ただし本来は使い過ぎを防ぐ機能で、制限時間までは普通に開けますし、iOSのバージョンによって項目の名前も変わっています。補助的な手段と考えましょう。

### ロックしたメモに移す

メモアプリで「カスタムパスワードを使用」を選んでロックしたメモは、iPhoneのパスコードでは開けません。少数の写真を確実に守りたい場合に向いています。

### 暗号化された保管庫アプリに移す

独自の鍵で写真を暗号化して保管するアプリもあります。保管庫アプリを使う場合は、[写真保管庫アプリは安全？](/ja/guides/are-photo-vault-apps-safe/)で確認ポイントを押さえてから選んでください。

## ヒントとよくある間違い

- **パスコードを人前で入力しない**：肩越しに入力を見られるのが、パスコードが漏れるよくある原因です。普段はFace IDを使いましょう。
- **スクリーンタイムパスコードを使い回さない**：iPhoneのパスコードと同じにしていたり、復旧に使うApple Accountのパスワードを相手が知っていたりすれば意味がありません。
- **初期設定の「普段いる場所」に頼り切らない**：「盗難デバイスの保護」の初期設定では、自宅や職場ではパスコードでも開けます。家族から守りたいなら「常に」を検討します。
- **iPadやMacの対策も忘れない**：アプリのロックは端末ごとの設定で、同期している端末には反映されません。
- **ロックの設定を確認する**：ロックと表示の設定がきちんと整っているかは、[秘密のアルバムを作る設定チェックリスト](/ja/guides/secret-photo-album-iphone/)で確認できます。
