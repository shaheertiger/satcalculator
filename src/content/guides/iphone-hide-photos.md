## 写真の非表示と削除の違い

写真を人目から遠ざけたいとき、まず迷うのが「非表示」と「削除」のどちらを使うかです。名前は似ていても、写真の行き先も、あとから元に戻せるかもまったく違います。

| | 非表示 | 削除 |
|---|---|---|
| 写真の行き先 | 「非表示」アルバム | 「最近削除した項目」→30日後に完全削除 |
| iCloud写真で同期しているほかの端末 | ほかの端末でも非表示になる | ほかの端末からも削除される |
| iPhoneやiCloudの容量 | 変わらない | 完全削除されると空く |
| 元に戻せるか | いつでも「再表示」できる | 30日以内なら「復旧」できる |
| 開くのに必要なもの（iOS 16以降） | Face ID / Touch ID / パスコード | Face ID / Touch ID / パスコード |

**残しておきたいけれど見られたくない写真は「非表示」、もう要らない写真は「削除」**と使い分けるのが基本です。ゴミ箱ボタンで「とりあえず消す」と、30日後にはiCloudやほかの端末からも消えてしまうので注意してください。

## 「非表示」アルバムで写真を非表示にする方法（iOS 26・iOS 27）

ここでは現行のiOS 26・iOS 27の画面を例にしています。ボタンの位置はバージョンによって少し違いますが、「非表示」というメニュー名は共通です。

### ステップ1：隠したい写真を選ぶ

写真アプリを開き、隠したい写真やビデオをタップして表示します。まとめて隠すときは、ライブラリで右上の「選択」をタップし、写真を順にタップします。指でなぞると連続して選べます。

### ステップ2：「その他」ボタンから「非表示」を選ぶ

画面の「その他」ボタン（…）をタップし、「非表示」をタップします。サムネールを長押しして出てくるメニューから「非表示」を選んでもかまいません。

### ステップ3：確認画面で「非表示」をタップする

確認が表示されたら、もう一度「非表示」を選びます。写真はライブラリから消え、「非表示」アルバムに移ります。

### ステップ4：「Face IDを使用」がオンか確認する

「設定」＞「アプリ」＞「写真」を開き、「Face IDを使用」がオンになっていることを確かめます。機種によっては「Touch IDを使用」「パスコードを使用」と表示されます。iOS 16以降は初期状態でオンです。

非表示にした写真を見たり戻したりするときは、写真アプリで「コレクション」＞「ユーティリティ」＞「非表示」を開き、「アルバムを表示」をタップして認証します。戻したい写真を開き、「その他」ボタンから「再表示」をタップするとライブラリに戻ります。

iOS 18では「コレクション」タブがなく、写真アプリの画面を上にスワイプした先の「ユーティリティ」に「非表示」があります。iOS 17以前は「アルバム」タブの「その他」の下です。設定画面の場所も次のように変わっています。

| iOSのバージョン | ロックの設定 | 「非表示」アルバムを隠す設定 |
|---|---|---|
| iOS 26・iOS 27 | 「設定」＞「アプリ」＞「写真」＞「Face IDを使用」 | 同じ画面の「非表示アルバムを表示」 |
| iOS 18 | 「設定」＞「アプリ」＞「写真」＞「Face IDを使用」 | 写真アプリ右上のアカウント＞「“非表示”アルバム」 |
| iOS 17 | 「設定」＞「写真」＞「Face IDを使用」 | 「設定」＞「写真」＞「“非表示”アルバムを表示」 |
| iOS 16 | 「設定」＞「写真」＞「パスコードを使用」など | 「設定」＞「写真」＞「“非表示”アルバム」 |

iPadでも操作はほぼ同じで、「非表示」アルバムは左上のサイドバーボタンから「ユーティリティ」を開くと見つかります。Macの写真アプリでは、写真をControlキーを押しながらクリックして「写真を非表示」を選ぶか、「command + L」キーを押します。Macでは「非表示」アルバムが初期状態でサイドバーに出ないので、メニューバーの「表示」＞「非表示アルバムを表示」を選び、Touch IDかログインパスワードで開きます。アルバムが見当たらないときの対処は[非表示アルバムはどこにある？](/ja/guides/hidden-album-location/)で詳しく説明しています。

## 非表示にしても変わらないこと

Appleの説明では、非表示にした写真は「ライブラリ」やほかのアルバム、ホーム画面の写真ウィジェットに表示されなくなります。一方で、写真そのものや、写真を開ける人の範囲はほとんど変わりません。

| 項目 | 非表示で変わるか | 補足 |
|---|---|---|
| ライブラリ・アルバム・ウィジェットでの表示 | 変わる（表示されない） | 「非表示」アルバムでのみ見られる |
| 写真のデータと容量 | 変わらない | iPhoneにもiCloudにも残る |
| パスコードを知っている人 | 変わらない | ロックはパスコードでも解除できる |
| 同じApple Accountの別の端末 | 変わらない | iCloud写真で非表示の写真も同期される |
| iCloud上の保護レベル | 変わらない | 標準のデータ保護では鍵はAppleが管理。エンドツーエンド暗号化には「高度なデータ保護」が必要 |
| 送信済み・共有済みのコピー | 変わらない | メッセージや共有アルバムのコピーは残る |

なお、iPhoneのストレージ全体はもともと「データ保護」という仕組みで暗号化されています。非表示はその上で「写真アプリの中でどこに表示するか」を切り替える機能で、写真を別の鍵で暗号化し直すものではありません。パスコードを知っている人まで遠ざけたいなら、後述の他の方法と組み合わせる必要があります。

## iPhoneで写真を隠す方法の比較

iOSの標準機能だけでも、写真を人目から遠ざける方法はいくつかあります。代表的なものを並べると次のとおりです。

| 方法 | 主な手順 | 開くのに必要なもの | 向いている場面 | 注意点 |
|---|---|---|---|---|
| 「非表示」アルバム | 写真の「…」→「非表示」 | Face ID / Touch ID / パスコード | 日常的な覗き見対策 | パスコードを知る人は開ける |
| 写真アプリごとロック（iOS 18以降） | アイコン長押し→「Face IDを必要にする」 | Face ID / Touch ID / パスコード | 写真アプリ自体を開かせたくない | 写真アプリは非表示フォルダには隠せない |
| ロックしたメモ | メモに写真を貼り、「ロック」 | 端末のパスコード、またはメモ専用パスワード | 少数の写真を別パスワードで守る | 元の写真は写真アプリに残るので削除が必要 |
| 暗号化された保管庫アプリ | アプリに取り込み、元写真を削除 | アプリ独自のパスコードなど | パスコードを知る家族から守りたい | アプリの信頼性を自分で見極める必要あり |
| 端末から移す | パソコンや外部ストレージに保存して削除 | 保存先の管理方法による | iPhoneに置いておく必要がない写真 | 「最近削除した項目」に30日間残る |

どの方法が正解かは、相手がどこまでiPhoneに触れられるかで決まります。隠したい相手ごとに整理すると次のとおりです。

| 隠したい相手 | 最低限やること | さらに強めるなら |
|---|---|---|
| 写真を見せるだけの友人・同僚 | 「非表示」にする | 「非表示アルバムを表示」をオフ |
| 子ども | 「非表示」にする | 写真アプリをロックし、パスコードを教えない |
| パスコードを知る家族・パートナー | パスコードを変更する | 別パスワードのメモや保管庫アプリへ移す |
| 同じApple Accountの共有iPad | iPadの写真同期を見直す | 家族用に別のApple Accountを用意する |
| 紛失・盗難時の第三者 | 長めのパスコードを設定 | 「盗難デバイスの保護」と「高度なデータ保護」 |

### スマホを貸す・写真を見せるだけの相手

相手はライブラリをスクロールする程度なので、**「非表示」アルバムに移すだけで十分なことがほとんどです。** iOS 16以降なら、うっかり「非表示」アルバムを開かれてもFace IDの確認が入ります。

### パスコードを知っている家族やパートナー

パスコードを知っていれば、「非表示」アルバムのロックはパスコード入力で解除できます。まずパスコードを変更して共有をやめ、そのうえでiPhoneのパスコードとは別の鍵を持つ方法を検討します。突破されうる経路と対策は[非表示アルバムのFace IDは解除できる？](/ja/guides/hidden-album-face-id-bypass/)で整理しています。

### 同じApple Accountを使う家族のiPadやMac

iCloud写真がオンだと、非表示にした写真も同期され、そのiPadの「非表示」アルバムにも同じ写真が入ります。iPadのパスコードを家族が知っているなら、そこから見られる可能性があります。iPad側だけ同期を止める方法は「iCloud写真の同期を止める方法」の記事で解説しています。

### 紛失や盗難が心配

まず守ってくれるのはパスコードと端末の暗号化です。そのうえで「盗難デバイスの保護」をオンにし、写真アプリをロックしておくと、普段いる場所から離れているときはFace IDかTouch IDでしかロックされたアプリを開けなくなります。

## iPhoneで写真を隠す他の方法

### 写真アプリそのものをロックする（iOS 18以降）

ホーム画面で写真アプリのアイコンを長押しし、「Face IDを必要にする」をタップすると、写真アプリ全体を開くのに認証が必要になります。ライブラリ全体を勝手に見られたくない場合に向いています。鍵はiPhoneのパスコードと同じです。

### ロックしたメモに入れる

メモアプリでは、メモごとにロックをかけられます。「設定」＞「アプリ」＞「メモ」＞「パスワード」で「カスタムパスワードを使用」を選べば、iPhoneのパスコードとは別のパスワードで守れます。写真をメモに入れたら、写真アプリの元の写真は削除しておきます。

### 暗号化された保管庫アプリに移す

独自のパスコードで写真を暗号化して保管するアプリを使う方法です。パスコードを知っている家族からも守りたい場合の選択肢になりますが、アプリの信頼性は自分で見極める必要があります。

### パソコンや外部ストレージに移す

iPhoneに置いておく必要のない写真なら、パソコンに読み込んだり、「ファイル」アプリから外部ストレージに保存したりしてから、iPhone側で削除する方法もあります。削除した写真は「最近削除した項目」に30日間残るので、そこからも削除しておきます。保存先のパソコンやストレージを誰が使えるかも確認してください。

これらの方法の具体的な手順とロックの強さの違いは[iPhoneの写真をロックする方法](/ja/guides/lock-photos-iphone/)にまとめています。

## ヒントとよくある間違い

- **「非表示アルバムを表示」をオフにする**：「設定」＞「アプリ」＞「写真」でオフにすると、写真アプリから「非表示」アルバムそのものが消え、隠していることに気づかれにくくなります。設定の全体像は[iPhoneで秘密のアルバムを作る設定チェックリスト](/ja/guides/secret-photo-album-iphone/)で確認できます。
- **共有ライブラリに入れない**：iCloud共有写真ライブラリに入れた写真は参加者全員に表示されます。隠したい写真は個人用ライブラリに置いておきます。
- **送信済み・保存済みのコピーを忘れない**：メッセージの画像、共有アルバムに追加した写真、SNSアプリやクラウドストレージに保存したコピーは、元の写真を非表示にしても残ります。
- **普通のアルバムを「秘密」にしない**：自分で作ったアルバムにはパスワードを設定できません。「秘密」という名前のアルバムでも誰でも開けます。
- **「非表示にしたから安全」と思い込まない**：非表示はパスコードを知っている人やApple Accountにアクセスできる人まで締め出すものではありません。知られている可能性があるなら、パスコードやApple Accountのパスワードを変えるほうが先決です。

> 「非表示アルバムを表示」をオフにすると、隠した本人も写真アプリからアルバムを開けなくなります。写真が消えたわけではないので、見たいときは同じ設定をオンに戻してください。慌てて写真を削除しないよう注意しましょう。
